# Результаты на H&M

Источник: успешный приватный запуск Kaggle, версия `364262984`:
https://www.kaggle.com/code/tulec21/thread-h-m-recommendation-lab?scriptVersionId=364262984

Полное время запуска: 295 секунд, CPU без ускорителя. Данные: 31 788 324 покупки;
последние 98 дней содержат 4 453 834 строки. Даты меток обучения: 9–15 сентября
2020; проверки: 16–22 сентября 2020. Признаки обучающей выборки заканчиваются
8 сентября, признаки проверки — 15 сентября.

Для обучения выбраны 3000 из 72019 покупателей соответствующей недели, seed=42.
Получено 296206 пар покупатель–кандидат, из них 1095 положительных.
Для оценки выбраны 5000 из 68984 покупателей следующей недели тем же seed.
Покупатели могут встречаться в обеих неделях: прогнозируется продолжение покупок,
а не перенос на полностью новую аудиторию.

| Подход | MAP@12 |
|---|---:|
| Популярность за последние недели | 0.0085425941 |
| Гибрид с фиксированными весами | 0.0292967253 |
| Обучаемый скоринг кандидатов | 0.0276539516 |

Обучаемая модель даёт MAP@12 примерно в 3,24 раза выше популярности. Абсолютная
разница — 0.0191113574; 95% парный bootstrap-интервал [0.0154308; 0.0226325].
Он отражает вариативность покупателей одной недели, а не разных сезонов.
Фиксированный гибрид выше обучаемой модели на этой выборке; статистическая
значимость именно этой разницы не оценивалась. Гиперпараметры после проверки
не менялись; модель для демо оставлена исходной, без выбора победителя по тесту.

Другие показатели обучаемой модели:

- полнота кандидатов: 0.149785;
- охват наблюдаемого каталога: 0.103222;
- 1275 cold-start покупателей: MAP@12 0.007989;
- 3725 покупателей с историей: MAP@12 0.034385.

Главное ограничение — генерация кандидатов: только около 15% реальных покупок
попадают в набор, который может ранжировать модель. Для следующего эксперимента
нужны более широкие кандидаты и несколько проверочных недель. Последнюю новую
неделю следует оставить нетронутой до финального сравнения.

Окружение Kaggle: Python 3.13.15, NumPy 2.1.3, pandas 2.3.3, scikit-learn 1.6.1.
Полный исходный JSON-отчёт сохранён локально в `artifacts/real/report.json`.
Истории пользователей и веса модели не входят в исходники для публикации.
