# Проверка ранжирования на одинаковых кандидатах

Сравниваем действующий расширенный гибрид, текущий классификатор и
[LambdaMART в LightGBM](https://lightgbm.readthedocs.io/en/stable/pythonapi/lightgbm.LGBMRanker.html).
Кандидаты, шесть признаков, пользователи и fallback для профилей без истории одинаковые.
Классификатор обучается на отдельных парах, а LambdaMART получает группы товаров
по покупателям. LambdaMART оптимизирует порядок с упором на верх списка;
итоговая оценка всех методов — MAP@12, а не внутренняя цель обучения.

Четыре проверочные недели начинаются 22 и 29 июля, 5 и 12 августа 2020 года.
Эти недели не были проверочными в предыдущих двух экспериментах, однако их
покупки могли входить в историю поздних окон. Для каждой проверки параметры
зафиксированы, модель обучается на метках предыдущей недели, а признаки
считаются строго по 98 дням до соответствующего прогноза. Используются 3000
покупателей обучения и 5000 проверки на окно с seed=42. Модели не подбираются
по результатам отдельных недель. Последняя неделя используется для итоговой
проверки заранее заданного правила, без настройки параметров.

Дополнительно рассчитываем верхнюю границу MAP@12 при идеальном порядке
имеющихся кандидатов. Для холодных пользователей граница учитывает неизменный
fallback. Это оценка потенциала ранжирования, использующая реальные покупки
задним числом; она не является результатом модели.

Правило допуска LambdaMART к отдельной проверке перед заменой демо: средний
прирост над гибридом положителен, победа минимум на трёх неделях из четырёх,
нижняя граница парного 95% bootstrap-интервала последней недели выше нуля.
Интервалы описывают неопределённость по покупателям внутри недели; они не
оценивают независимость недель. Эта проверка не переключает демо автоматически.

Воспроизведение: `python -m pip install ".[ranking]"`, затем запуск
`notebooks/hm_ranking_comparison.ipynb` в Kaggle с официальными данными H&M.
Ноутбук записывает только агрегированные метрики; модели и прогнозы покупателей
не экспортируются. Параметры не требуют GPU.
