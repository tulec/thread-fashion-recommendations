# Как представить проект

## Измеренный результат первого эксперимента

«Разработал систему рекомендаций одежды на H&M: генерация кандидатов и
градиентный бустинг. На временной проверке из 5000 покупателей получил
MAP@12 0.02765 против 0.00854 у популярности. Реализовал обработку новых
покупателей, тесты на утечку данных и интерактивное демо».

Уточнение для обсуждения: фиксированный гибрид показал 0.02930 и оказался лучше
обучаемой модели; это отражено в отчёте. Оценка выполнена на выборке одной недели,
не на официальном тесте соревнования.

## После обучения на реальных данных

Краткое описание: «Разработал двухэтапную систему рекомендаций одежды на
исторических данных H&M: генерация кандидатов и обучаемое ранжирование.
Реализовал временную проверку MAP@12, обработку новых пользователей и Streamlit-демо».

Добавляйте только измеренные числа из `report.json`, указывая период, размер
выборки и baseline. Если модель хуже популярности, прямо укажите результат и
разберите причину — это тоже содержательная исследовательская работа.

Пока есть только синтетический запуск, корректное описание: «Реализовал прототип
рекомендательной системы и проверил код на синтетических данных; подготовил
временную валидацию для H&M». Не называйте его завершённым исследованием H&M.

## Что объяснить на собеседовании

- Почему случайное разделение покупок создаёт утечку будущего.
- Почему оценка кандидатов ограничивает итоговый MAP@12.
- Почему популярность — обязательная точка сравнения и fallback.
- Чем повторная покупка одежды отличается от предложения нового товара.
- Почему офлайн MAP не доказывает рост выручки.
- Как меняется качество по новым и знакомым пользователям.
- Что произойдёт при смене сезона, каталога и поведения покупателей.

## Следующие эксперименты

Сначала повторить оценку на нескольких неделях и проверить стабильность. Затем
сравнить вклад каждого источника кандидатов, добавить контент для новых артикулов,
измерить задержку и стоимость массового расчёта. Настраивать параметры на
отдельных неделях, сохраняя последнюю неделю нетронутой до финального сравнения.
