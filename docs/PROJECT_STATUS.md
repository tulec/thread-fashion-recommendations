# Состояние проекта

- Реализованы генерация кандидатов, три способа ранжирования и временная оценка.
- Локальный синтетический запуск завершён; пять тестов пройдены.
- Автономный ноутбук загружен в приватный Kaggle-проект:
  https://www.kaggle.com/code/tulec21/thread-h-m-recommendation-lab
- Правила H&M согласованы пользователем; официальные данные подключены.
- Первая версия `364261956` остановлена: рекурсивный обход каталога изображений
  задерживал поиск CSV. Во второй версии поиск ограничен несколькими каталогами.
- Версия `364262984` успешно завершена за 295 секунд. Метрики проверены и
  перенесены в `docs/RESULTS.md`; JSON-отчёт и 100 профилей демо сохранены локально.
- CSV содержит 31 788 324 покупки; в окно 98 дней загружено 4 453 834 строки.
- Последняя дата исходных данных — 2020-09-22. Выбрано 3000 покупателей для
  обучения ранжированию и 5000 для оценки следующей недели (seed=42).
- Создан публичный репозиторий `tulec/thread-fashion-recommendations` для
  исходников и агрегированных метрик. Конфиденциальные артефакты в него не входят.

Демо запускается командой `python -m streamlit run app.py`.
Данные, веса и реальные рекомендации находятся в игнорируемой папке `artifacts/`.
