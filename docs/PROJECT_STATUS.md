# Состояние проекта

- Исходный и расширенный генераторы сравниваются с фиксированным гибридом и
  обучаемым скорингом на четырёх неделях по 5000 покупателей.
- Протокол зафиксирован до результатов в коммите `f1d03ff`; параметры ранжирования
  не менялись по итогам контрольного периода.
- Три ранние недели выбирают расширенный гибрид с очень небольшим преимуществом.
  Контрольная неделя не подтверждает устойчивого улучшения общего MAP@12.
- Полнота кандидатов на контрольной неделе выросла с 15,05% до 23,12%.
- Приватный запуск Kaggle: `364277161`. Первый эксперимент `364262984` сохранён
  отдельно для истории. Данные соревнования подключены после согласования правил.
- Для сравнения загружено 6 114 608 покупок за 133 дня; каждое окно признаков
  ограничено 98 днями строго до начала целевой недели.
- Девять тестов покрывают метрики, запрет будущих данных, новые профили,
  расширение кандидатов, выбор по ранним неделям и соответствие экспорта выдаче.
- Публичный репозиторий: https://github.com/tulec/thread-fashion-recommendations
  В него входят исходники и агрегированные результаты; истории и веса приватны.

Демо запускается командой `python -m streamlit run app.py`. При наличии нового
экспорта оно использует `artifacts/selected/demo.json`; исходная версия сохранена
в `artifacts/real/`. Подробности: `COMPARISON.md` и `COMPARISON_RESULTS.md`.
